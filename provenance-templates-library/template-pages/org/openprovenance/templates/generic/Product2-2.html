• Name: Product2-2
  • Fully Qualified Name: org.openprovenance.templates.generic.Product2-2
  • IRI: https://openprovenance.org/templates/org/openprovenance/templates/generic/Product2-2
  • Purpose: The template Product2-2 describes the transformation of two inputs into two distinct outputs.
  • Context: It is a general transformation applicable to many contexts.
  • Design considerations: Built on triangles, using multiplicity to accommodate multiple inputs and outputs, with explicit dependencies.
  • Automation: ttfs/config-generic.json

  • Details:

    This template has two inputs: input1 and input2; two outputs: output1 and output2; an activity: transforming; an agent; and a plan. It is a direct instantiation of org.openprovenance.templates.generic.Transformation1, which uses multiple values for input and output.

    In this template, the bindings file contains no “linked” property linking the variable output to input (unlike Parallel2). As a result, output1 is derived from both input1 and input2, and output2 is derived similarly.

    In contrast, Parallel2 links the input to the output variables, implying that each output is derived from a single input.

    An application of Product2-2 is integer division, which takes a dividend and a divisor and produces a quotient and a remainder. Both the quotient and the remainder are derived from the dividend and the divisor. Likewise, a shuffle operation that takes two heaps of cards, shuffles them, and creates two new heaps of cards is an instance of Product2-2.
