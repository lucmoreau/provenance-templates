## ✅ S1: The five ReSpec documents (2026-10-16)

**Asked** (`PROMPT.md`): with ReSpec, starting from the prov-jsonld submission (`~/IdeaProjects/prov-jsonld/source.html`),
an overview, a primer (a file processing pipeline, not the book's box), a specification (template formatting in PROV,
variables, the `tmpl:` namespace, bindings schemas, TTF files; non-normative CLI, executables, Maven plugins), the
algorithms (instantiation, merge), the library; a TODO and a DONE file. Luc, during the work: single editor Luc Moreau,
previous version <https://openprovenance.org/prov-template-2014-06-07/>, Dong Huynh and Danius Michaelides as former
editors.

**What was done.**
- `common/config.js`: one ReSpec configuration for the family (`ptmConfig`), `specStatus: "unofficial"`, the editor,
  the former editors, the previous-version link (`otherLinks`; ReSpec ignores `prevVersion` for unofficial drafts), the
  shared bibliography (the five documents, PROV-TEMPLATE-2014, PROV-JSONLD, the TSE paper, ProvToolbox, the vocabularies).
  `common/style.css`.
- `prov-template-overview/` — PROV-TEMPLATE-OVERVIEW: the four principles (three from 2014, plus "described and
  automated"), the artefacts at a glance, the roadmap table of the family, the namespaces, acknowledgements.
- `prov-template-primer/` — PROV-TEMPLATE-PRIMER: a weather institute's nightly pipeline (upload, clean, combine,
  convert, validate) — a non-ML ETL chain, to stay clear of the book's box and of its PLEAD/gzip file examples. Sections:
  first template (`var:`, `vargen:`, `tmpl:label`, `tmpl:startTime`), a transformation, several values, linked
  variables (9 derivations without `tmpl:linked`, 3 with), statements left out (unbound curator), merging the run into
  one bundle, a bindings schema, a TTF. All 23 examples are `data-include`d from `examples/`, generated by ProvToolbox.
- `prov-template/` — PROV-TEMPLATE: templates, variables and their positions (group / attribute / bundle variables),
  the `tmpl:` vocabulary with linked variables, templates generated from templates, bindings (model, JSON, the 2014
  PROV representation as deprecated), bindings schemas, template indexes, TTFs (structure, paths, schema check, the
  `ptm_instantiating`/`ptm_merging` records); non-normative tools: `provconvert`, `prov-template-process`, the Maven
  plugin's goals, the template compiler. `schemas/`: copies of `bindings-schema.json`,
  `template-transformation-file-schema.json` (ProvToolbox 95386ae29) and the library's index schema.
- `prov-template-algorithms/` — PROV-TEMPLATE-ALGORITHMS: positional slots, grouping, group usage, index order,
  substitution, generated values, attribute expansion, statements kept and left out, bundle identifier, `tmpl:order`,
  merge, errors. The 2014 examples re-run on today's ProvToolbox (`examples/`) — the expansion matches 2014's Example 4
  statement for statement.
- `prov-template-library/` — PROV-TEMPLATE-LIBRARY: identification (FQN, IRI, path), organisation, derivation
  (instantiation with variables, merge, the library's own provenance), the families with the purposes of their 28
  pages, namespaces, conventions, adding a template, known issues.
- `Makefile`: `examples` (TTF run and template figures, JVM in UTC), `validate` (ajv), `serve`.

**Evidence.**
- Each document rendered in the built-in browser from `make serve`: ReSpec reports 0 errors, 0 warnings for all five;
  no empty `data-include`.
- `make examples` regenerates the primer's outputs with `prov-template-process` (7 instantiations, 1 merge, the
  `default-qn` schema check passing on every jsonld output); `make validate`: the 6 bindings files and the bindings
  schema valid against `bindings-schema.json`, the TTF against its schema, the index against the index schema.
- Every behaviour the primer and the algorithms describe was run: linked variables in the template and in the bindings
  (3 derivations), an unbound plan (`-`), unbound nodes and attributions dropped, the bundle merge.

**Findings filed** as S2–S20 (rulings on `tmpl:if`/`tmpl:notif`, relations with empty mandatory slots, affiliation,
