The vocabulary is identified by http://openprovenance.org/provtoolbox/, the prefix its three namespaces share. The terms ProvToolbox itself writes and reads in provenance documents, beyond PROV-DM, provext, the OpenProvenance vocabulary and the template vocabulary. They share the prefix http://openprovenance.org/provtoolbox/ and fall into three namespaces: box, the toolbox's own (a datatype the value converter falls back on); dot, the hints a document carries for its rendering as a graph; and sum, the figures the summariser stamps on a summary graph. Every attribute in the three namespaces is toolbox-internal: the visualiser never lists one in a statement's attribute box, and other tools pass them through untouched.

boxhttp://openprovenance.org/provtoolbox/ns#
dothttp://openprovenance.org/provtoolbox/dot/ns#
sumhttp://openprovenance.org/provtoolbox/summary/ns#

The kind of each term is shown on its card: an attribute is an rdf:Property, paired with a value on a statement; the one datatype is an rdfs:Datatype.

The toolbox namespace box

Namespace http://openprovenance.org/provtoolbox/ns#, prefix box. ProvToolbox's own namespace (NamespacePrefixMapper.TOOLBOX_NS): what the toolbox names for itself rather than for a document.

box:UNKNOWN_TYPEhttp://openprovenance.org/provtoolbox/ns#UNKNOWN_TYPE
rdfs:labelunknown type
rdfs:commentThe datatype the value converter answers when it cannot tell the XSD type of a value: a Java object of no class the converter knows, where a typed literal was expected. A document never writes it deliberately; its presence in output marks a value whose type was lost on the way in (ValueConverter.getXsdType, Name.QUALIFIED_NAME_UNKNOWN_TYPE).
rdf:typerdfs:Datatype
rdfs:seeAlsoxsd:anyType

The dot namespace dot

Namespace http://openprovenance.org/provtoolbox/dot/ns#, prefix dot. Rendering hints (NamespacePrefixMapper.DOT_NS): an attribute on any statement, element or relation, overriding the default the visualiser would pick for its node or edge. Values are Graphviz's; the Mermaid and SVG passes read them too, and the first value counts when several are given.

dot:fillcolorhttp://openprovenance.org/provtoolbox/dot/ns#fillcolor
rdfs:labelfill colour
rdfs:commentThe fill colour of the node, a Graphviz colour name or #rrggbb; setting it also sets the style to filled. The one hint the toolbox's own examples use most, to tell kinds of entity apart at a glance.
rdf:typerdf:Property
rdfs:rangexsd:string
dot:colorhttp://openprovenance.org/provtoolbox/dot/ns#color
rdfs:labelcolour
rdfs:commentThe stroke colour: of a node's outline, or of an edge.
rdf:typerdf:Property
rdfs:rangexsd:string
dot:fontcolorhttp://openprovenance.org/provtoolbox/dot/ns#fontcolor
rdfs:labelfont colour
rdfs:commentThe colour of the node's label text. Read by the Scala graphics module; the Java visualiser leaves the font colour to its defaults.
rdf:typerdf:Property
rdfs:rangexsd:string
dot:stylehttp://openprovenance.org/provtoolbox/dot/ns#style
rdfs:labelstyle
rdfs:commentGraphviz style words, comma-separated (filled, dashed, dotted, bold, rounded, …), replacing the default style of the node or edge outright. The template connection graph writes dot:style="dashed" on the derivation between two versions of a port.
rdf:typerdf:Property
rdfs:rangexsd:string
dot:urlhttp://openprovenance.org/provtoolbox/dot/ns#url
rdfs:labelurl
rdfs:commentA link to attach to the node or edge, followed when the rendered graph is clicked (Graphviz URL, an anchor in SVG output).
rdf:typerdf:Property
rdfs:rangexsd:anyURI
dot:sizehttp://openprovenance.org/provtoolbox/dot/ns#size
rdfs:labelsize
rdfs:commentA number scaling the drawing: on an element, the width of its node (the value, in inches, times 0.75); on a relation, the pen width of its edge. Distinct from sum:size, a count the summariser writes and the visualiser shows in the label rather than in the geometry.
rdf:typerdf:Property
rdfs:rangexsd:double
rdfs:seeAlsosum:size

rdfs:labeltooltip
rdfs:commentThe text shown when the pointer rests on the node or edge; a long one is cut to the visualiser's maximum tooltip length and ended with an ellipsis.
rdf:typerdf:Property
rdfs:rangexsd:string

The summary namespace sum

Namespace http://openprovenance.org/provtoolbox/summary/ns#, prefix sum. What the summariser stamps on a summary graph (NamespacePrefixMapper.SUMMARY_NS): each node stands for the instance nodes sharing a provenance type at the chosen level, each edge for the instance edges between two such classes, and these figures say how many.

sum:sizehttp://openprovenance.org/provtoolbox/summary/ns#size
rdfs:labelsize
rdfs:commentHow many nodes or edges of the instance graph the summary node or edge stands for: the size of its equivalence class. Zero on a node the summary keeps for a type no instance node carries.
rdf:typerdf:Property
rdfs:rangexsd:int
rdfs:seeAlsodot:size
sum:nbrhttp://openprovenance.org/provtoolbox/summary/ns#nbr
rdfs:labelnumber
rdfs:commentThe number of the provenance type the summary node stands for, in the summariser's index of types at that level: the integer its identifier is minted from, kept as an attribute so the type can be looked up without parsing the name.
rdf:typerdf:Property
rdfs:domainprov:Entity ∪ prov:Activity ∪ prov:Agent
rdfs:rangexsd:int
sum:counthttp://openprovenance.org/provtoolbox/summary/ns#count
rdfs:labelcount
rdfs:commentThe number of nodes or edges of the instance graph with the summary node's type. Declared by the summariser beside sum:size, which it writes with that meaning; reserved, and not written at present.
rdf:typerdf:Property
rdfs:rangexsd:int
rdfs:seeAlsosum:size
sum:level0http://openprovenance.org/provtoolbox/summary/ns#level0
rdfs:labellevel-0 type
rdfs:commentOne of the level-0 descriptors — the primitive prov:type values — folded into the provenance type the summary node stands for; one attribute per descriptor. Written only when the summariser is asked for level-0 descriptions.
rdf:typerdf:Property
rdfs:domainprov:Entity ∪ prov:Activity ∪ prov:Agent
rdfs:rangexsd:string
