OpenProv Ontology

In this section, we provide details about OpenProv Ontology ... .

The ontology is identified by https://openprovenance.org/ns/openprov#; its terms are in the namespace https://openprovenance.org/ns/openprov#, prefix openprov. The vocabulary the OpenProvenance template library and ProvToolbox use in provenance documents beyond PROV-DM and provext: the statements a summarising relation was folded from, the roles of the parties to a change of collection, and the kinds of activity and derivation that change a collection. Distinct from provext, the minimal extension PROV-JSONLD needs for its regular JSON shape, whose classes this vocabulary builds on.

The ontology imports https://openprovenance.org/ns/provext#.

Object Properties

Each property is declared as owl:ObjectProperty; it is optional on the relation named by its domain and points at a statement that relation summarises.

On prov:Attribution and provext:Membership

openprov:hadActivityhttps://openprovenance.org/ns/openprov#hadActivity
rdfs:labelhad activity
rdfs:commentThe activity the relation arose from: for an attribution, the activity that generated, invalidated or derived the entity while the agent was associated with it; for a membership, the activity that placed the member in the collection. A sub-property of prov:hadActivity, whose domain PROV-O states as prov:Influence and, more precisely, as the union of Delegation, Derivation, End and Start; an attribution or membership carrying this property is therefore entailed to be an Influence, and, under the precise domain, a member of that union, which PROV-O declares nothing to contradict.
rdfs:subPropertyOfprov:hadActivity
rdfs:domainprov:Attribution ∪ provext:Membership
rdfs:rangeprov:Activity
openprov:hadGenerationhttps://openprovenance.org/ns/openprov#hadGeneration
rdfs:labelhad generation
rdfs:commentFor an attribution, the generation of the attributed entity by the activity it arose from; for a membership, the generation of the collection by that activity.
rdfs:domainprov:Attribution ∪ provext:Membership
rdfs:rangeprov:Generation

OpenProv JSON-LD Context

In this section, we provide a description of the JSON-LD context ... .

The context builds on https://openprovenance.org/prov-jsonld/context.jsonld.

The context declares @version 1.1.

It declares the following prefixes.

prefixnamespace IRI
openprovhttps://openprovenance.org/ns/openprov#

Each of the following keys names a type of relation and carries a scoped context: the keys it lists are defined only inside an object of that type; a key mapped as a property gives the IRI as predicate, a reverse property as the predicate pointing back at the object.
